{%- comment -%} Prints the URL of a page in the current page language: French paths are written as is (the root), /fr is prepended on French pages. Usage: Param: path (the English path), lang (optional, defaults to page.lang). {%- endcomment -%} {%- assign localized_lang = include.lang | default: page.lang | default: "en" -%} {%- if localized_lang == "fr" -%}/fr{%- endif -%}{{ include.path }}
